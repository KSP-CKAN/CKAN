ckan:// test page

Test links for the ckan:// handler. Operations are defined in Core/IO/ProtocolRouter.cs. A running CKAN picks the URL over a pipe, otherwise a new one is launched.

`focus`

Highlight a mod in the list.

  • ckan://focus?mod=JNSQ
  • ckan://focus?mod=Astrogator

`search`

Apply a search filter. %40 is an escaped @ for author search.

  • ckan://search?q=engine
  • ckan://search?q=%40Nertea

`install`

Add one or more mods to the changeset. mod:version pins a version. A version missing from the registry falls back to latest compatible.

  • ckan://install?mod=RealSolarSystem&mod=ROEngines&mod=ROTanks&mod=ROCapsules&mod=ROSolar
  • ckan://install?mod=JNSQ:0.10.0&mod=Astrogator:1.0.0
  • ckan://install?mod=Astrogator:0.10.5
    Downgrade, assuming a newer version is installed

`install` pop ups

  • ckan://install?mod=Astrogator:9.9.9
    9.9.9 is not a real version of Astrogator
  • ckan://install?mod=RealSolarSystem&mod=NotARealMod
  • ckan://install?mod=NotARealMod&mod=AlsoNotReal
  • ckan://install?mod=DDSLoader
    Assuming a modern KSP version
  • ckan://install?mod=MechJeb2:2.5.8.0
    A pinned version that only supports KSP 1.1
  • ckan://install?mod=Astrogator
    Assuming it's already installed

bad links

  • ckan://uninstall?mod=JNSQ
    `uninstall` isn't a real operation
  • ckan://install?id=JNSQ
    `id` should be `mod`
